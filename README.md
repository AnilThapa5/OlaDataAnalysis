# OlaDataAnalysis

## 📌 Overview

This project analyzes an **Ola ride booking dataset** using **Microsoft Excel** for data cleaning and preprocessing, and **Power BI** for creating interactive dashboards and visualizations.

The objective is to uncover valuable business insights from ride booking data, helping stakeholders make informed, data-driven decisions.

---

## 🎯 Project Objectives

- Analyze ride booking trends over time.
- Understand booking status distribution.
- Identify the most frequently used vehicle types.
- Evaluate customer and driver ratings.
- Analyze ride cancellations and their reasons.
- Study revenue generated through different payment methods.
- Identify top customers based on booking value.
- Explore ride distance patterns.
